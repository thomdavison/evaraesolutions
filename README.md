# Evarae Solutions

A small, dependency-free marketing site built with HTML, CSS, and JavaScript. GitHub Pages publishes it directly from the `main` branch.

## Before publishing

- In `script.js`, replace `hello@evaraesolutions.com` with the email address that should receive enquiries. The contact form opens the visitor's default email app with the enquiry details filled in; it does not submit to a server.
- The sample website shown in the hero is an illustrative design, not a live client project.

## GitHub Pages deployment

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select the `main` branch and `/ (root)` folder, then save.
4. Push changes to `main`; GitHub Pages will publish them automatically.

No workflow, build step, package installation, or server configuration is required. The first deployment may take a few minutes.
